REST API 안내

HTTP 요청으로 도서 데이터를 관리할 수 있습니다.

GET/api/books전체 도서 목록 · 검색: ?q=키워드GET/api/books/:id도서 한 권 조회POST/api/books새 도서 등록PUT/api/books/:id도서 정보 수정DELETE/api/books/:id도서 삭제GET/api/health서버 상태 확인

POST/PUT 요청은 JSON 형식을 사용합니다. 필드: title(문자열), author(문자열), year(숫자), status(available 또는 borrowed).
